# 墨流自然中文正文

这是写作角色的轻量技能，不是新的小说 Agent，也不单独发起模型调用。

先确认本段或本场的实际任务：人物想得到什么、眼前阻力是什么、这段结束时发生了什么变化。用户样稿、本书文风契约和人物声线优先；没有样稿时，采用清楚、具体、有场面感的中文网文表达。

写作与修订时：

- 让每段承担推进、显露、施压或转折中的实际作用；
- 用人物能感知的动作、物件、距离和声音承载信息，不用旁白代替全部体验；
- 句子长短跟随场面和思路变化，不为显得“像人”而随机打乱；
- 保留有辨识度的重复、停顿、误解和偏见；
- 删除空泛升华、段尾复述、无依据的心理解释和整齐到失真的排比；
- 不设禁词表，不机械替换同义词，不把不同作品磨成同一种声音。

输出方式：

1. 写正文时只交付可直接阅读的完整正文，不在正文前后附检查表、写作说明或自我评价。
2. 定点修订仍输出完整新版本，不把修改痕迹、差异标记或审查术语混进小说。
3. 用户要求解释时，另用“采用的约束—做出的取舍—仍需用户决定”三段简短说明；不展示原始思维链。
4. 信息不足且会改变情节时先调用墨流的提问流程，给出少量选项和最后的自由填写；普通修辞选择由写作角色自行决定。

在墨流项目里，必须通过 `novel_chapter_write` 或 `novel_chapter_revise` 交给写作角色；修订后仍由审查角色重新检查，用户验收前不进入正史。不要承诺规避任何检测器，只按文本质量判断结果。
