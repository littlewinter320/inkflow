# 墨流连载结构、钩子与伏笔

这是 Writer 的规划引导技能，不是新的小说 Agent，也不额外发起模型调用。它负责告诉 Writer 怎样把灵感变成可持续的章节结构，但不替代用户对故事方向的选择。

## 如何工作

1. 从全书读者承诺和主角长期困境开始，先确定“故事为什么还能继续”，再划分卷与篇章。
2. 当前篇章展开到章节卡；远期只保留方向，避免把数百章写成很快失效的伪精确计划。
3. 每章先确定不可逆变化，再反推目标、阻力、决定和后果。没有变化的章节要合并、改造或明确其兑现任务。
4. 为每条伏笔记录生命周期：
   - 种下：读者能注意到异常，但暂时不能完整解释；
   - 推进：补充证据、改变解释或提高代价；
   - 转义：旧线索获得新的合理含义；
   - 兑现：答案改变人物状态或下一阶段目标；
   - 延期：必须给出新证据或新代价，不能只是继续不说。
5. 章末先写成一个具体问题，再检查三件事：读者是否知道自己缺什么；答案是否值得等；人物是否已经采取下一步行动。
6. 短线钩子、中线伏笔和长线承诺交替运行。篇章高潮至少兑现一项前期承诺，同时用兑现后的后果打开下一篇章。
7. 避免所有章节同一种结尾。危险、揭示、决定、代价、错误胜利、关系破裂、新目标和余韵应随章节功能轮换。

## 如何输出

规划输出必须按“全书罗盘—当前卷—当前篇章—连续章节卡”排列。每张章节卡清楚写：

- 本章功能、目标、阻力、决定、后果、不可逆变化；
- 本章释放的信息；
- 伏笔种下/推进/转义/兑现/延期；
- 主钩子类型与读者可复述的问题；
- 它怎样衔接上一章，又给下一章留下可执行起点。

给用户解释规划时，只展示采用的约束、节奏取舍、伏笔账本和风险，不展示原始思维链。需要改变未来篇章时先预览影响并询问；已接受正文不能被规划静默覆盖。
