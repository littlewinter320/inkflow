# 墨流（InkFlow）发布说明 · 0.4.1

0.4.1 聚焦输入、对话和参数控制，并将桌面版更新与 VS Code 扩展彻底分开。

## 用户可见变化

- 回答速度提高为默认 20 字/秒，并保留“立即显示”。
- 输入框新增一键提示词优化、优化说明、原文对照与撤回。
- 对话历史扩展到最近 100 轮，可搜索、查看时间并继续旧话题。
- 墨宝增加摸头、找灵感、陪写、逗一逗等互动。
- 设置页新增“高级生成参数”，Writer、Reviewer、Memory Keeper 可分别调整 temperature、top_p 与可选 top_k。
- 桌面版显示与打包版本统一为 0.4.1。

## 兼容性与安全

- `top_k` 只向配置了该值的兼容接口发送；接口明确拒绝时会撤掉该可选字段后重试。
- 提示词优化器不执行提示词，不扩大正史、费用、删除或发布授权。
- 对话历史只保存用户可见问答与路由摘要，不保存原始思维链。
- VS Code 扩展保持独立版本，不参与桌面软件的更新检测。
