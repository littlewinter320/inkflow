# 墨流（InkFlow）

墨流是一款面向中文长篇小说的四 Agent 桌面创作工具。你只需要用自然语言说明目标，Coordinator 会像 AI 产品经理一样理解、拆解和派工，再由 Writer、Reviewer 与 Memory Keeper 在明确边界内完成规划、写作、审查与正史维护。

当前桌面版：**0.4.3**

## 下载与更新

- 普通用户请直接从 [GitHub Releases](https://github.com/littlewinter320/inkflow/releases/latest) 下载 Windows 安装包，不需要安装 Python、Node.js 或阅读源码。
- 安装后可在软件右上角点击“检查更新”。桌面版只跟随桌面版发布，不会被 VS Code 扩展的版本号干扰。
- 小说项目保存在你自己选择的文件夹中；更新软件不会删除项目。

## 0.4.3 主要能力

- 新增可自定义工作区：小说结构、Coordinator 对话、批注/版本面板均可独立显示或隐藏；支持左右放置 AI 对话、四种工作预设，以及可拖拽或精确设置宽度。本机保存个人布局，不影响小说项目内容。
- 0.4.2 的更新发布机制继续保留：每个桌面版本都由同名 GitHub Release 的 `latest.yml` 与安装包共同驱动在线更新。

## 0.4.2 主要能力

- 回答默认按 **20 字/秒**淡入，可随时点“立即显示”。
- 输入框新增“一键优化提示词”，先补全目标、上下文、约束和交付格式；保留原文，可一键撤回。
- 对话历史最多保留 100 轮，可搜索并把旧问题带回输入框继续讨论。
- 墨宝新增摸头、找灵感、陪写、逗一逗等互动反馈。
- Coordinator、Writer、Reviewer、Memory Keeper 各自拥有独立的高级生成参数：temperature、top_p 和可选 top_k；默认不发送固定 top_k。
- “查看思考”只展示判断摘要、依据与工具过程，不展示模型原始思维链。
- 选中文字后可以批注或只修订选区；新版本保留旧稿，不会自动写入正史。
- 可保存自定义写作预设。
- 上下文容量面板每四秒刷新；接近软预算时只定向压缩低权威、低相关资料，不会随机删除正史或当前指令。
- 协作看板会显示 Coordinator 的任务交接、Reviewer 的问题、批次临时记忆和可接收批次；批量章节仍按顺序逐章提交正史。
- 上下文面板会解释保留/压缩理由，并允许锁定最多六条工作资料；锁定不等于写入正史。
- 旧项目的正史正文数据库升级会先显示影响，确认后先在本地创建 SQLite 一致性备份再迁移。

## 四个正式 AI Agent

- **Coordinator**：理解自然语言、日常交流、拆解任务、受控派工、汇总分歧并在必要时向你澄清。
- **Writer**：规划、写作、定点修订。
- **Reviewer**：只审查并引用证据，不直接修改正文。
- **Memory Keeper**：只从用户已经接受的正文提取正史补丁。

其中后三个是小说生产 Agent。Coordinator 不写正文、不批准审查、也不直接提交正史；它提交结构化任务单，由确定性 Novel Engine 校验后执行。

草稿只有在你明确验收后才会进入正史。已进入正史的内容若要修改，墨流会先展示影响范围与检查点，不会静默覆盖。

## 第一次使用

1. 打开墨流，点击“新建”。
2. 在“设置”里填入兼容接口地址、模型名称与 API Key；密钥保存在 Windows 凭据库。
3. 用自然语言告诉 Coordinator 题材、主角、基调或开篇想法；没有完整想法时，它会整理需求并安排 Writer 给出方向。
4. 先看规划和草稿，再决定是否审查、修订或验收。

## 仓库目录

仓库只把三个产品部分放在一级目录，便于区分：

- `agent/`：小说编排引擎。
- `desktop/`：Windows 桌面应用。
- `extension/`：独立的 VS Code 扩展，当前不随桌面版一起发布。
- `development/`：当前构建脚本与必要开发说明；普通用户无需进入。

开发说明统一收在 [development/README.md](development/README.md)。

## 数据与安全

- API Key 不写入小说文件、Git、日志或 Trace。
- 单次模型调用只接收一个编译后的 Context Packet。
- 墨流不展示或保存模型原始思维链，只展示可复核的公开判断摘要。
- 删除、付费调用、正史回改和数据库迁移等高影响操作需要明确确认。
- PowerShell 默认关闭；只有用户在设置里了解影响并明确开启后，才允许工具在当前小说项目目录内执行。
