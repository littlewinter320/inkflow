# 墨流（InkFlow）

墨流是一款面向中文长篇小说的四 Agent 桌面创作工具。你只需要用自然语言说明目标，Coordinator 会像 AI 产品经理一样理解、拆解和派工，再由 Writer、Reviewer 与 Memory Keeper 在明确边界内完成规划、写作、审查与正史维护。

当前桌面版：**0.5.3**

## 下载与更新

- 普通用户请直接从 [GitHub Releases](https://github.com/littlewinter320/inkflow/releases/latest) 下载 Windows 安装包，不需要安装 Python、Node.js 或阅读源码。
- 安装后可在软件右上角点击“检查更新”。桌面版只跟随桌面版发布，不会被 VS Code 扩展的版本号干扰。
- 小说项目保存在你自己选择的文件夹中；更新软件不会删除项目。

## 本地普通话语音

语音功能嵌入墨流桌面端，不是独立软件，也不是第五个 Agent。默认采用轻量 `sherpa-onnx` + ONNX 组件；在“设置 → 语音”中点击一次即可下载约 360MB 的普通话识别与朗读模型。它不需要 Python、Torch 或 CUDA，适合普通 CPU，模型和音频只保存在本机。

- 对话输入框可录制普通话，识别结果可只填入输入框，或按开关直接发送。
- 每条对话右下角可单独朗读；正文或草稿可把全文或选区送入听读中心。
- 听读中心识别显式说话人，为旁白和角色分配不同男女音色；无法可靠判断时回退到旁白并标记待确认。
- 长篇转换按片段写入后台任务，可暂停、继续、取消；离开听读页不会停止。应用退出时任务记为中断，下次可继续。
- 克隆窗口支持上传或录制参考音频、填写参考文本、调整语速/音量/朗读要求，并可准备本地微调计划；准备计划不会直接训练。

Qwen3-TTS 是可选的高品质组件，不随安装包强制安装。在“设置 → 语音 → Qwen 高品质组件”点击“安装 Qwen 并一键适配”后，墨流会在获得确认后使用本机 Python 安装依赖、下载模型并切换到 Qwen；磁盘空间、下载时间和显存占用会在按钮前明确提示。若安装包所在电脑没有 Python 3.12/3.13，可设置 `INKFLOW_PYTHON` 指向 `python.exe`。不安装 Qwen 时，轻量模式仍可独立使用；声音克隆只在 Qwen 可用时启用。

开发环境可以按需安装对应组件：

```powershell
pip install -e ".\agent[lightvoice]"  # 轻量 sherpa-onnx
pip install -e ".\agent[voice]"       # 可选 Qwen/FunASR
```

声音设置还包括引擎选择、计算设备、采样率、分段字数、短音频缓存上限和调试日志开关。预设名称是墨流内部的通用“女声旁白、明快女声、温柔女声、男声旁白、沉静男声、坚定男声”，不内置或冒充真人、明星与未经授权的热门声线。各项目与模型权重可能采用不同许可证，分发前应逐项复核模型卡和商用条款。

## 四个正式 AI Agent

- **Coordinator**：理解自然语言、日常交流、拆解任务、受控派工、汇总分歧并在必要时向你澄清。
- **Writer**：规划、写作、定点修订。
- **Reviewer**：只审查并引用证据，不直接修改正文。
- **Memory Keeper**：只从用户已经接受的正文提取正史补丁。

其中后三个是小说生产 Agent。Coordinator 不写正文、不批准审查、也不直接提交正史；它提交结构化任务单，由确定性 Novel Engine 校验后执行。

草稿只有在你明确验收后才会进入正史。已进入正史的内容若要修改，墨流会先展示影响范围与检查点，不会静默覆盖。

完整工作流为：自然语言需求 → Coordinator 任务单与固定工作流 → 书罗盘、卷、篇章和章节卡 → 唯一 Context Packet → Writer 候选方向（可选）与主笔草稿 → 多维预审（可选）和正式 Reviewer 审查 → Writer 定点修订与新版本重审 → 用户验收 → Memory Keeper 正史补丁预览 → 用户确认 → SQLite 事务提交与检查点 → Coordinator 汇总。Agent 有疑问或驳回时，通过绑定任务、章节、版本、Context Packet 和证据的协作消息交流；最多两轮，仍有分歧便暂停相关分支并只向用户问最小问题。

## 第一次使用

1. 打开墨流，点击“新建”。
2. 在“设置”里填入兼容接口地址、模型名称与 API Key；密钥保存在 Windows 凭据库。
3. 用自然语言告诉 Coordinator 题材、主角、基调或开篇想法；没有完整想法时，它会整理需求并安排 Writer 给出方向。
4. 先看规划和草稿，再决定是否审查、修订或验收。

## 仓库目录

仓库只把三个产品部分放在一级目录，便于区分：

- `agent/`：小说编排引擎。
- `desktop/`：Windows 桌面应用。
- `extension/`：独立的 VS Code 扩展，当前不随桌面版一起发布。
- `development/`：当前构建脚本与必要开发说明；普通用户无需进入。

开发说明统一收在 [development/README.md](development/README.md)。

## 数据与安全

- API Key 不写入小说文件、Git、日志或 Trace。
- 单次模型调用只接收一个编译后的 Context Packet。
- 墨流不展示或保存模型原始思维链，只展示可复核的公开判断摘要。
- 删除、付费调用、正史回改和数据库迁移等高影响操作需要明确确认。
- PowerShell 默认关闭；只有用户在设置里了解影响并明确开启后，才允许工具在当前小说项目目录内执行。
