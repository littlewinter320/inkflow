# 墨宝动画素材

这些 WebM 由用户提供的六段 720×720、24 fps 原动画处理得到。处理只改变透明通道：移除浅色背景与会在画面角落切换位置的生成平台水印，不改动作内容，不覆盖原文件。

状态对应关系：

- `mobao-idle`：普通待机、呼吸和眨眼。
- `mobao-thinking`：理解自然语言、规划或调用工作流时。
- `mobao-waiting`：需要用户补充或确认时。
- `mobao-success`：一次写作、审查、保存或打开操作完成时；播放一次后回到待机。
- `mobao-rest`：工作中断或出现错误、等待用户检查后恢复时。
- `mobao-welcome`：欢迎页或首次进入；播放一次后停在自然姿势。

`.poster.png` 是相应视频的首帧透明封面。界面真正播放的是完整 `.webm`，不是低帧率分镜图。
