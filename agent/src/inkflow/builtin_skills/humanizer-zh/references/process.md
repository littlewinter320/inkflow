# 中文自然表达：在原任务里改善句子

## 使用边界

写作、获准的修稿和实际表达审核可使用。纯逻辑、纯记忆、代码与机器字段不用，也不另发一次“去AI味”模型请求。作者明确声音和本书样稿优先，不能为了检测器分数改变故事。

## 1. 先读懂句子负责什么

输入：当前段落、前后语境、视角、人物关系、作者要求和保留范围。
操作：辨明句子承担事件、观察、反应、转折还是信息交接；人物是在回避、试探、告知还是争辩。
输出：真正影响阅读的具体位置。没有问题的句子可以原样保留。
验收：不按词语或符号出现次数判定“像AI”，不先套一种统一口气。

## 2. 选择合适的表达方法

输入：具体问题、人物声音与叙事功能。
操作：按表达标准去除空泛总结、无作用解释和机械复述；按写法标准处理对白、内心、长短句、停顿和分段。长句承载连续动作时可保留，转折或情绪断裂需要停顿时才拆。
输出：原任务所需的新正文、替换或审核建议。
验收：不强加吐槽、网络梗和口语，不把所有人物改成同一个人。
展示：正文用自然段；列表、标题或表格仅用于对比、说明和结构化交付，不搬进小说叙事。

## 3. 标点按实际语意选

引号：标明直接说话、引用或必要特殊指代，不给普通名词处处加引号。
逗号与句号：意脉连续时连接，需要落定或转向时结束，不机械按固定字数拆句。
破折号：用于真实打断、转折或补说，不替代每个普通停顿。
省略号：用于欲言又止、声音延续或省略，不给每段加悬念。
括号与内心：视角和文体允许时短用；需要读者持续跟随的情绪写进叙事，不塞一串旁白。
顿号、冒号及列表：确有并列、提示或列举才用；正文不用工作清单式逐项汇报。
验收：这些是语境判断，不是禁用清单、密度配额或强制模板。详细写法及反例在craft-standard。

## 4. 根据责任决定改还是只提意见

Writer正在新写：直接在原授权目标内应用。
Writer已获改稿许可：只处理锁定范围，必要衔接仍须保留事实。
Editor表达审核：引用原句说明阅读影响和建议，不自动改正文。
输出：与原任务同一Schema和交付类型，不追加两稿、自评分或“去痕迹报告”。
失败交接：事实与表达纠缠、原文缺失或保留范围不明时先定位，不能静默改剧情。

## 5. 对照、结束与学习

对照修前修后的人物、事实、否定、确定程度、因果和消息来源。“可能”不能变“一定”，传闻不能变事实。原审核、结构及版本门禁继续保留。
取消时不把半段当完整正文；恢复使用原任务与原技能版本。有效结果交回原写作或审核链，不额外跑一遍润色。
真实效果和作者反馈留本书；自动经验只是后续选择参考，沉默不等于满意，不能因此把某个词永久拉黑或自动改技能。
