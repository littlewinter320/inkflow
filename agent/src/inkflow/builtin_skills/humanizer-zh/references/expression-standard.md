# 中文自然表达的适用标准

依据Humanizer-zh与Humanizer的公开方法，针对小说重新表述。来源与许可证见references/sources.md。以下只诊断具体表达问题，不以单词、符号或句型推断文本来自AI。

## 信息优先

保留姓名、数字、否定、范围、条件、时间、归因和确定程度。重复同一信息可合并，不同信息不能因为排比或篇幅删掉。没有细节时允许概括，不能编数字或经历让句子显得具体。小说新写细节仍受当前创作授权、正史及人物所知约束。

## 模式与保留条件

| 观察线索 | 什么时候改 | 什么时候保留 |
| --- | --- | --- |
| “不是X而是Y” | 只用来拔高、虚设反对者，两边不增加信息 | 纠正真实误解、人物反驳或必要对照 |
| 同义碎句 | 连续重复同一意思，拖慢动作 | 各句有新信息，或短句承载反应与重音 |
| 格言式收尾 | 凭空宣布深意，取代具体后果 | 人物确有此口吻，或句子提供真实立场 |
| “首先、其次、与此同时” | 没有顺序/同时关系，只是模板衔接 | 确有顺序、并行或转折，删掉反而含混 |
| 三项排比、四字词 | 只凑整齐，堆同义修饰 | 各项独立、符合文体或人物说法 |
| 广告腔、无名权威 | 没有依据地夸大、替代论证 | 故事里角色故意夸张、宣传或说谎 |
| 被动句和名词化 | 使施事者不清或拖沓 | 文体需要、未知施事者、强调承受者 |
| 破折号、括号 | 只装饰强调、塞作者说明 | 打断、改口、人物短念头或必要插话 |
| 省略号和感叹号 | 靠一串符号代替情绪或悬念 | 真正迟疑、话未完、喊话或强烈反应 |
| 礼貌与客服句 | 混进正文的“下面为你”“希望有帮助” | 角色之间有目的的客套和礼貌 |
| 总结和解释 | 重复读者已看懂的同一结论 | 补充独立信息、必要推断或人物态度 |
| 网络梗、口头禅 | 人人同一套、不符年龄题材关系 | 角色自然会说，场景也承担相应作用 |

## 同次修订流程

先顺读理解文体和保留项，只改确有问题的部分；再对照施事者、因果、顺序、否定与程度；最后读是否顺口。无需另起模型请求或默认交两稿。审核只指出原句与具体影响，“像AI”本身不是扣分理由。

## 符号、格式和机器内容

中文直接对白保留成对“”，内引可用‘’；不要为了少标点删掉语法需要的引号。长短句按意义，不能以标点次数切句。代码、命令、路径、URL、链接目标、ID、YAML和JSON字段不作为散文润色。引用原句用于核证时逐字保留，不悄悄修正成更好看的证据。

## 示例（教学虚构）

“这是一个意义非凡的行动，它标志着他迈向成长。”若上下文只有“他终于把欠的钱还了”，可以直接写这件事和人物当下反应；不能凭空补写欠款数额、童年经历或对方原谅。若人物故作庄严地说这句话形成讽刺，则可能应保留原口吻。
