# 中文自然表达

借鉴Humanizer-zh与Humanizer的方法，针对中文小说保留人物声音、事实、否定、时序、归因和确定程度。不是词语黑名单，也不能判断作者身份或保证通过检测器。

## 什么时候用

主动说去套话、润色或@humanizer-zh时可用；被动只进新写正文、已授权修稿和实际表达审核。纯逻辑核对、记忆提取或机器字段不用，不另发一次润色请求。

## 工作方法

新写、改稿和表达审查共用[中文小说写法标准](references/craft-standard.md)：说明句子怎样接、对白按什么关系说、各种标点何时用或不用、内心戏和分段怎样安排。当前作者要求和本书声音优先；只在本次真正涉及的段落使用，不把示例情节复制进小说。

1. 输入当前段落、文体、作者要求和保留范围，先辨明这句话承担的信息、反应或叙事作用。
2. 按[表达标准](references/expression-standard.md)找确实空泛、重复、歧义或不合人物口气的位置；没有问题的句子可以保留。
3. 写作与修稿角色在原授权内改；审核角色只给有原句和影响的建议，不自行落稿。
4. 顺读并对照修前修后的信息、因果、角色认知和声音，防止把“可能”写成“一定”、计划写成发生、传闻写成事实。
5. 只交当前任务原本要求的最终内容；不附两稿、自评分、词语命中清单或去痕迹仪式。

## 不强套的规则

必要的长句、排比、四字词、礼貌对白、反驳、括号短念头、连接词、破折号和省略号都可以有用。只有实际影响当前段落时才改，不为了短而拆句，不给所有人物加吐槽或网络梗。

## 交付与反馈闭环

交付类型沿原任务：Writer交正文或已授权替换，Editor只交有定位的建议。对照人物、事实、否定、归因、确定程度及视角，原结构和版本门禁仍须通过。事实与写法纠缠或范围不明先定位，不能悄悄改剧情；断流片段保持未完成，恢复沿原任务。作者效果反馈留本书，不把沉默当满意或将某词永久禁用。技能内容的改进先形成候选。

作者可在设置阅读[完整流程说明](references/process.md)；标点的使用与不使用条件仍以craft-standard中的语境判断为准。
