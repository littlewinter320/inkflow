# 规划追问：从分歧到可执行共识

## 何时开始和何时退出

作者要求先推敲、主动点名，或既有规划流程进入真正影响目标的未决选择时使用。普通缺章号、可自行检索的事实、明确可执行的写作任务不进入长访谈。作者说停止、已有信息足够，或者目标不再有效时退出。

## 1. 先核已有答案

输入：当前原话、上轮问题、作者真实回答、本书可得事实和已经授权的范围。
操作：删除已回答、已过期以及可自行查明的问题；区分事实不足、工程或故事取舍和个人偏好。
输出：本轮仍然影响下一步的一小组选择。
验收：不能把推荐当同意，不能因为换措辞重复问同一问题。
展示：先说明具体影响，再问作者能回答的选择。

## 2. 按依赖提问

输入：未决选择、可行方案及各自代价。
操作：最多3个相互独立的问题；依赖前题的后题等答案之后再问。每题给清楚选项、影响、必要推荐理由和自由回答空间。
输出：当前clarification_questions，使用真实待答身份。
验收：不能在问题里塞角色调度、哈希、字段和内部诊断；范围或费用问题不与审美偏好混为一题。

## 3. 解释回答并保留分歧

输入：与原问题绑定的作者答复。
操作：记录明确选择及其适用范围；含混回答只追问会改变方案的部分。作者说“不知道”时可提出有标记的建议，不能当授权。
输出：已经确认的共识、尚未决定的部分与必要下一题。
验收：沉默、预选项、推荐和假设均不等于提交的答案；新消息改变目标时先重新核原题有效性。

## 4. 收敛并交回原目标

输入：足够明确的共识、原授权、原任务来源。
操作：信息足够就停止追问。原目标已授权且范围未扩大时交回现有规划流程；仅讨论则交讨论结论。
输出：简短共识和实际下一步，不擅自写正文或发布规划。
失败交接：原题失效或快照缺失时保留记录并说明缺口，不凭现在的设置恢复旧任务。
经验记录问题是否有效、作者纠正与真实结果；不能把少问问题本身视为质量提升，也不自动改技能。
