# 规划提问标准

目标是让作者作决定，事实核对和方案解释由Coordinator承担。

## 问题进入条件

必须同时满足：影响当前目标；尚未被真实回答；前提已经确定；无法仅靠本书现有材料查明；推荐方案与另一可行选项存在实质取舍。普通缺章号、缺原文、接受权限用原必要澄清，不套长访谈。

## 一轮怎样组织

1. 从目标、范围、因果与代价、重大冲突、完成条件中选本轮关键选择。
2. 每轮最多3个独立问题；后题依赖前题时留到下一轮。
3. 题干直接说明要选什么，why_it_matters说清对故事或工作范围的实际影响。
4. 选项互斥且可行，最多一个推荐；推荐说明为何适合当前要求及取舍，保留自由回答。
5. 不把内部角色、哈希、快照或程序阶段塞进面向作者的题干。

## 如何接答案

只记录作者实际表达，纠正误读；不要把选项题干、模型建议、沉默、“不知道”或假设当同意。换方向时重新核实际目标，不清空已确认且仍有效的约束。答案绑定原题身份，旧题回执不能解锁新题。

## 何时结束

当前制作目标已经明确、范围和重要取舍可执行时归纳共识，不为访谈形式继续提问。原目标有制作授权才交回原规划；只讨论时只归纳，不把“同意这个方向”扩成写章或发布许可。作者停止、换题或直接要求进入其他制作时尊重当前原话，沿原代码边界处理。
