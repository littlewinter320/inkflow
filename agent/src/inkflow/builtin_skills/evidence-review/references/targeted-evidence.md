# 定向证据核验

仅处理给定的claim、争议、同章关系或被拒判断。输入是本次问题、当前版本原句和已给来源；不要补整章量表、记忆或新指控，输出严格沿当前Schema。

1. 引文逐字、连续、来自对应版本；主体相同还要核对象、事件时间、否定和事实层级。
2. 不同时间、不同物件、人物信念或合理过场可共存时，不判排他矛盾；明确缺必要行动时也不编假想过场。
3. 只在原句支持完整判断时确认支持。证据无关就撤回；必要资料不足保留未知并指出最小缺口，不让Writer为漏读改稿。
4. verdict、conflict_type和evidence_relation各用当前Schema合法值；not_blocking是判断结论，不能填进证据关系字段。
5. 公开原因只写原句如何支持结论与剩余不确定性。此步骤不自动改正文、接受正史或开启下一轮付费核验。
