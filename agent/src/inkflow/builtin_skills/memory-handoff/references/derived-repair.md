# 派生摘要与事件索引修补

适用前提：原任务实际需要失效派生资料，且输入已经提供足够同版原文和真实身份。不是每次交接的必做项目，也不发额外摘要模型调用。

## 章节摘要

只有读到同版完整已接受章，才可在原分派调用的source_summary_rebuilds交最多6份候选。每项复制真实chapter_no、source_version/source_hash，写忠实chapter_summary和1至6条可逐字定位的evidence_quotes。

只读片段、来源未接受、版本不明或没有实际需求时留空。不增加未发生事实，不用Writer说明、未来规划或参考设定补摘要；不造多级“摘要的摘要”。

## 事件索引

source_event_rebuilds只描述实际读到范围的事件。indexed_scene只证明相应场景读过；whole_chapter_fallback或明确的同版完整原文才支持整章范围。状态转移、时间和人物认知保持身份；事件关系目标仍须真实给出。

程序核对原文确实装入、来源版本与关系后才保存派生缓存；被拒绝或尚未采用的候选不能说已经重建。

## 失败交接

缺原文写清来源ID、所需范围及原因，沿现有补读机制继续。无法定位引用时撤下候选或保留缺口，不改正史、删原文或假写“已修复”。
