# 记忆交接

当前memory_owner从真实正文整理可核验增量。日常通常由Editor承担，启用记忆专项时按原分工交Memory Keeper；技能不会新增角色或重复一份请求。

## 触发边界

仅在实际记忆分派、记忆候选修补或引用补核节点装入。作者主动点名仍不能跳过正文版本、审核或接受。未来规划、Writer说明、参考设定和传闻不直接变成客观正史。

## 部分与交接

| 部分 | 输入 | 操作 | 输出 |
| --- | --- | --- | --- |
| 核身份 | 当前正文与来源版本、已有候选 | 确认本章与已接受前史身份，旧版不覆盖新版 | 有效来源范围；错版则停止 |
| 分认识 | 正文事实、人物判断、传闻、未来安排 | 按[记忆标准](references/memory-standard.md)分别记录，保留说话人和不确定性 | objective、belief、rumor等合法候选 |
| 写增量 | 已有事实、人物所知、时间线和本章变化 | 仅交新增或有据变化；事件时间未知明确unknown，不猜ID | 有原句支持的facts、events及变更 |
| 交设定与承诺 | 已有记录、真实合同、当前动作 | 同对象沿record_id和expected_revision更新；兑现逐项核触发条件 | setting_updates与threads候选，未证实项不提交 |
| 修派生资料 | 明确失效需求与同版完整来源 | 仅必要时读[派生修补标准](references/derived-repair.md) | 有版本与引句的重建候选，不改正文 |
| 交回引擎 | 完整当前输出结构、未决缺口 | 自查引用、身份、时间、根对象与内层字段 | 记忆候选；程序核对后才可能正式提交 |

## 输出与展示

输出根结构以本次Schema为准：主交接ModeCheckOutput的verdict、confidence和summary在顶层，memory_patch在内层，纯记忆分派assessments为空；记忆修补返回当前MemoryPatch；引文选择返回EvidenceSelectionBatch，不把短补核扩成完整报告。不把source_comparisons放进memory_patch。公开说明讲实际新增或缺少什么；候选和正式提交分别表述。

## 验收、提交与恢复

结构、时间、来源、原句及当前角色检查通过才有有效候选；正文接受前不写成正史。正式提交只能由原引擎核版本和权限执行，不能凭记忆角色自述关闭待办。缺证回原来源补核，冲突交责任角色或作者；取消或状态未知先查是否已写入，再续未完成项，不能重复提交。经验只记录真实结果，不能把学习到的候选升级为事实，技能改写仍先给候选。

作者可在设置查看[完整流程说明](references/process.md)；主交接、修补和引文选择各读当前分支标准。
