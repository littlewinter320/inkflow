# 墨流（InkFlow）

墨流是面向中文长篇小说的本地创作工作台。扩展把自然语言主控、四级规划、章节写作、证据化审查、正史记忆和分支式回退放进 VS Code；小说文件仍留在你的电脑上。

![墨宝](media/mobao.png)

## 适合谁

- 完全没有故事想法，希望先由模型给出开书方向的人；
- 已有题材或大纲，需要稳定写几十到几百章的人；
- 希望在正文旁边批注、对比版本、调用编程助手协作的专业写手。

## 工作方式

墨流固定使用三个小说角色：

1. 写作角色负责规划、写草稿和定点修订。
2. 审查角色只检查正文，必须指出引用、扣分原因和修改方向。
3. 记忆角色只处理用户已经验收的正文，把事实、人物状态和伏笔同步进正史。

基础流程是：书籍设定 → 全书/卷/篇章/章节卡 → 草稿 → 审查 → 用户验收 → 正史记忆。草稿不会因为生成成功就自动进入正史。

## 扩展界面

左侧墨流图标中有两个区域：

- **创作主控**：查看正史字数、章节和开放线索；和墨宝互动；填写章节号后生成规划、写草稿、审查或验收；也可以直接输入自然语言。
- **小说结构**：打开书籍设定、当前规划、正史状态、章节、审查报告、规划判断和批量草稿。

编辑 Markdown 时，还可以选中文字，在侧栏或右键菜单中添加批注，或让 Writer 只替换这一段。局部修订只适用于未验收草稿，历史版本不会被静默覆盖，修改后必须重新审查。

回答会按默认 10 字/秒逐字淡入，也可以立即显示。执行中会实时列出状态；完成后可展开查看公开判断摘要和可复核详情。这里不展示模型的原始思维链。内置快捷预设之外，还可以给当前工作区添加自己的写作预设。

当目标存在真正影响成品的分岔时，扩展会弹出中文选择框，解释每个选项的影响；最后固定提供“其他”供自由填写。也可以点击“让墨流先问我”主动补全想法。询问频率与桌面版设置共用。

## 第一次使用

1. 安装墨流 Windows 桌面版；它包含本地小说引擎。
2. 在桌面版中配置模型接口与密钥。扩展不会把密钥写入项目文件。
3. 用桌面版新建小说，或打开已有墨流项目。
4. 在 VS Code 中打开该小说文件夹，再点击左侧“墨流”。
5. 在“创作主控”中讨论方向并生成四级规划，然后开始写章。

发布版扩展会自带本地引擎；源码开发时也可在设置中指定引擎或 Python 路径。

## 常用操作

- `墨流：自然语言讨论或安排任务`
- `墨流：生成四级规划`
- `墨流：写当前章节草稿`
- `墨流：让审查角色检查当前章节`
- `墨流：验收当前章节进入正史`
- `墨流：批注选中文字`
- `墨流：让写作角色修订选中文字`
- `墨流：创建安全检查点`
- `墨流：查看任务记录`
- `墨流：为当前工作区配置 MCP`

所有命令都可以从命令面板调用。写作、审查和验收也可以直接用自然语言描述范围，例如：“批量写第 8 到 12 章，每章写完就审查，但先不要验收。”

## 与编程助手协作

执行“为当前工作区配置 MCP”后，墨流会合并 `.vscode/mcp.json`，不会覆盖其他服务。兼容的编程助手可以用自然语言调用同一个小说引擎、同一套正史和同一套门禁。

## 数据边界

- 模型密钥只来自系统凭据库或环境变量，不进入小说、日志和版本库。
- `.inkflow/inkflow.db` 是正史数据库；宿主和扩展都不会直接改它。
- 已验收正文的修改会先形成提案，确认影响后再进入写作、审查和记忆同步流程。
- 界面展示公开判断、证据、工具状态和可复核结论，不展示或保存模型原始思维链。

## 当前平台

0.4 发布包包含 Windows x64 本地引擎，支持 Windows 10/11。其他系统可从源码运行 Python 引擎，但当前商店包不承诺开箱即用。

遇到问题可到 [GitHub Issues](https://github.com/littlewinter320/inkflow/issues) 提交可复现步骤；请不要附上模型密钥。
