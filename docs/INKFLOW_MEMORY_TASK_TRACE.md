# 记忆任务追踪的公开说明

本地运行观察记录已留在开发机，不上传小说原文、人物资料、项目路径和运行文件。公开版本只说明核验方法与结论边界。

一次历史观察沿 Writer 的输入与输出、责任角色同次记忆候选、临时补丁、引擎接受事务、正文版本与事实来源、后续任务的实际输入核对。能确认特定已接受来源经过存储后进入后续模型请求；这不能证明模型正确理解或采用，也不等于新源码已经验证。

另一个已接受章的派生摘要已过期，原文和事实来源仍可定位。当前检索排除失效摘要，必要时核验版本并回源原文；原任务确实需要时才由原记忆责任角色在任务预算内重建独立缓存，不改正文与原提交时间。

实际输入清单区分正史、任务临时、作者偏好、参考与设计四种用途。检索命中、最终装入、发送给模型和模型在输出中有据采用分别记录。原始运行、事务、内容哈希和用量留在用户本地；供应商余额失败单列，不冒充记忆或检索错误。

公开源码定位：[retrieval.py](../agent/src/inkflow/retrieval.py)、[context.py](../agent/src/inkflow/context.py)、[engine.py](../agent/src/inkflow/engine.py)、[完整分析](INKFLOW_COMPLETE_ANALYSIS.md)。0.7.4 的本次检查和发布证据见[发布记录](RELEASE_0.7.4.md)，历史观察不计入本次检查。
