# 墨流（InkFlow）0.2 发布说明

## 这次交付是什么

墨流 0.2 是可安装的 Windows 长篇小说工作台，同时提供 VS Code 扩展和通用 MCP。它把此前需要在终端里完成的核心工作搬到桌面界面，但没有增加第四个小说 Agent：

- Writer 负责规划、写草稿与定点修订；
- Reviewer 负责有证据的审查，不直接改正文；
- Memory Keeper 只从用户已验收的正文同步正史；
- 自然语言主控只理解、确认和路由；Novel Engine 负责确定性步骤与文件事务。

## 桌面版新增

### 项目中心

“项目”页集中展示正史字数、草稿/已接受章节、开放线索和基于当前状态生成的下一步建议。建议只会放进对话框，不会未经用户发送就执行。

### 长任务状态与恢复

写作、审查、规划、批量草稿、篇章复审和公开资料处理会记录完成、失败、取消或中断状态。关闭软件后再次打开，墨流会识别已经退出的引擎进程，并把遗留任务标为“已中断”。

一键重跑只开放给边界明确的草稿、审查、规划、检查点和公开资料任务。自然语言整句任务、验收和正式回退不会一键重跑，因为原话可能包含正史写入或破坏性意图；用户需要回到对话中重新说明并确认。

### 停止当前任务

对话或快捷工作流运行时可以点击“停止任务”。已完整落盘的草稿会保留；未验收内容不会因此进入正史。停止是协作取消，不保证撤销模型供应商已经处理的请求费用。

### 检查点与分支式回退

用户可以手动创建同时覆盖正史 SQLite 与受管理 Markdown 的检查点。回退必须先展示新增、覆盖、移入可恢复回收区和不变文件，再经用户确认执行。执行前墨流还会保存当前安全点，并建立新的恢复分支；不会用删除文件或 Git 重置代替小说正史回退。

### 编辑、批注与版本

桌面编辑器支持 Markdown、字数/段落/对白比例统计、选区批注、历史快照对比和全文搜索。直接修改已接受正文时，编辑器只保存为“未应用提案”，不会静默覆盖正史；后续仍需 Writer、Reviewer、用户验收与 Memory Keeper 同步。

### 参考资料工作台

可导入 TXT/MD，或读取无需登录的公开网页并生成结构、节奏与表达特征卡。参考分析用于抽象方法和题材研究，不会把原文自动拼进小说。番茄页面若变成动态空壳或结构改变，界面会给出诊断，后续再更新专用适配器。

### 墨宝动态吉祥物

用户提供的六段墨宝动画已经处理为桌面应用可用的透明 WebM，并分别用于欢迎、待机、思考、等待、成功与出错/休息状态。安装包图标也使用墨宝视觉。应用不会依赖原始 MP4 路径。

## VS Code 0.2

VSIX 包含本地引擎，可在小说树中打开核心文档、章节、规划判断、审查和批量草稿；支持选区批注、Writer 定点修订、Reviewer 审查、项目状态、任务记录、安全检查点和 MCP 配置。扩展合并 `.vscode/mcp.json` 时保留已有服务。

## MCP 0.2

在既有规划、写作、审查、记忆、批量草稿、篇章复审、回退、参考资料、文档搜索与批注工具之外，新增只读 `novel_task_history`，供 Claude Code、VS Code、TRAE、Codex 等兼容宿主读取任务状态。它不返回模型原始思维链。

## 数据升级影响

本次升级不会迁移 `.inkflow/inkflow.db`，也不会仅因打开项目就改写已接受正文。桌面辅助库 `.inkflow/studio.db` 的结构版本升至 2，并自动增加 `task_runs` 表。这里保存：

- 文档历史快照与未应用提案；
- 行级批注；
- 手工故事圣经和场景笔记；
- 桌面/编辑器任务状态与小型重跑参数。

`studio.db` 不保存 API Key、模型原始输出或原始思维链。删除它不会删除小说正史，但会丢失上述桌面辅助记录。

用户可见的新文件主要是桌面/扩展发布物和本说明。小说项目仍沿用 `BOOK.md`、`PLAN.md`、`STATE.md`、`DIALOGUE.md`、`chapters/`、`planning/`、`reviews/` 与 `batches/`。

## 模型与上下文默认值

- 默认面向 DeepSeek 的 OpenAI 兼容接口，也允许用户填写其他兼容模型；
- 常用上下文软目标 256K，硬上限 512K，可在界面调整；
- 单次模型输出上限 16K tokens；
- DeepSeek 思考模式默认开启，默认强度为 `high`；思考模式下官方说明 `temperature` 与 `top_p` 不生效，因此界面不提供无效的采样滑块；
- 每次调用只接收一个由多来源编译出的 Context Packet，避免把大量零散摘要文件同时塞给模型；
- 不读取或展示供应商原始逐步推理，只展示约束、证据、判断摘要、阶段与工具状态。

实际可用上下文仍受所选模型和供应商接口上限约束。如果接口拒绝参数或发生输出截断，墨流会报错并阻止有风险的正史提交。

模型兼容依据：[DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/) 与 [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 安装与构建产物

- Windows 安装包：`desktop/release/InkFlow-Setup-0.2.0.exe`
- VS Code 扩展：`vscode-extension/release/inkflow-vscode-0.2.0.vsix`
- 本地引擎：`dist/engine/inkflow-engine.exe`

源码发布构建命令：

```powershell
.\scripts\build-release.ps1
```

## 当前边界

- 0.2 是私密预览版，不承诺所有 OpenAI 兼容供应商都支持完全相同的 reasoning、context 和采样参数。
- 批量草稿在用户验收前只使用临时连续性账本，不写正史；批次结束后仍由用户决定接受、局部修订或调整未来规划。
- 不提供供应商原始思维链。过程面板展示的是可复核工作摘要，不是隐藏推理的转录。
- 不绕过登录、付费墙、验证码或访问控制；受限资料应由用户以有权使用的 TXT/MD 导入。
- 0.2 没有云同步、多人协作或自动 GitHub 发布；小说和数据库默认留在用户电脑。
