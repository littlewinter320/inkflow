后续源码将同版已做补读的审查直接交接具体条件，不再新增外围Coordinator规划调用；相关断言通过。该提前停止分支没有再对真实项目重复收费验证。

## 扩展追加范围

用户在桌面打包后明确追加VS Code扩展重设计，并确认接口转入指第三方模型API配置导入与扩展内连接检查。复用共享provider.configure/test，不另建网络或凭据体系；配置卡在无小说工作区也可使用。模型诊断、日志和来源定位按扩展实际命令提供。审计发现配置验证失败也会先改凭据，已在共享底层修复，使用原设置合并校验先预检，再写系统凭据；密钥非文本拒绝，空值不改旧凭据。针对这些新增源码再次封装引擎、桌面和VSIX，最终附件以收尾校验为准。
