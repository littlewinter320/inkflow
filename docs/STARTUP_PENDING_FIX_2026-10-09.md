# 2026-10-09 桌面启动、待办收尾与开发入口修复

源码现为 0.7.4。本文保留故障依据与源码修复，最终打包、版本及上传状态以 RELEASE_0.7.4.md 为准。

## 本机故障依据

截图对应启动器等待 90 秒，Electron 主进程仍在，只有 GPU/网络进程，没有界面渲染进程；本次启动没有写入 app.started。窗口创建前同步调用的 Windows 快捷方式读取/改写处于关键路径。移除该路径并显示窗口后，同一源码入口成功打开首页。PNG 的 iCCP 警告仍存在，不能把它当成已确认的故障根因。

现有项目只读查看发现 28 条 open 协作议题，部分绑定旧正文版本或已经处理的消息；未通过宿主脚本批量改写用户数据库。新源码在墨流空闲打开项目及会话资料准备时核验并收尾。

## 已改入口

- desktop/electron/main.ts：取消同步快捷方式操作；创建可见窗口；加载成功恢复显示并记录 window.loaded；加载失败显示可操作的错误与日志入口；捕获启动异常；第二次打开显示既有窗口。保持 userData 和项目路径身份。更新下载后的提示与明确重启安装行为一致。
- desktop/scripts/dev.mjs、desktop/package.json：启动 Electron 前完成当前主进程编译，防止 wait-on 把遗留 main.js 当作本轮编译结果。
- scripts/InkFlowLauncher.cs、InkFlowLauncher.manifest、build-development-launcher.ps1、start-desktop-hidden.ps1：D:/墨流/dev-launcher/墨流 InkFlow.exe 为本地开发入口，嵌入既有墨宝图标与墨流名称。asInvoker 保留用户选择的权限层级；不修改 Windows 脚本宿主。桌面原入口先备份，桌面和开始菜单新入口已经登记。
- agent/src/inkflow/database.py：遗留空议题、已完成消息、过期消息和旧正文版本议题收尾；同议题重复指派保留最新，同秒按 rowid；不合并不同任务或独立问题，不凭旧 pass 清除记忆分歧。
- agent/src/inkflow/project.py：原生候选来源即时合并，延期只保存安排；区分可执行、决定、耗尽和进行中；原任务完成关闭关联诊断；补齐来源后关闭实际缺口；执行卡修订映射定点修订或复审，当前共享门禁通过才关闭复审断点。
- agent/src/inkflow/terminal_session.py：处理、查看、留到下次均有本地绑定入口；恢复保留原 run/task 配置；本地恢复及定点核对至多两次；未耗尽手改可恢复原候选；普通新待办不把已经完成的无关任务变成等待；延期安排本身完成，事项仍留存。
- agent/src/inkflow/app_server.py、manual_edits.py：提供当前待办；已关闭、已过期、缺待答来源或耗尽的议题不继续调用角色；尝试在远端调用前保存，异常和中断占次；过期回复不写回。已验证完成的原任务旧记录只展示历史。
- desktop/src/App.tsx：待办有从断点处理、查看问题和留到下次入口；关联诊断聚合到原任务；历史任务不再计入当前活动数量。
- docs/MOBAO_ANIMATION_INTEGRATION.md：窗口内墨宝移动、结果引导和点击适配的规划，含 12 个视频提示词。已接入窗口内移动和摘要展示，真实产物只读按钮预览；专用移动与指向视频仍待后续素材。

## 本次验证与限制

第一轮启动修复之后已用实际窗口观察到墨流首页，版本 0.7.3、最近项目和模型配置提示可见。开发原生启动器已在 D 盘编译一次，读取其 FileDescription 与 ProductName 均为“墨流 InkFlow”，快捷方式原入口已备份。桌面前端及主进程 TypeScript 检查通过。agent/scripts/check_pending_closure.py 是本次最小离线检查，覆盖议题收尾、同秒去重、独立问题、原身份恢复、耗尽停止、关联任务、规划复审、原生来源和延期结果，不调用真实模型、不写真实书稿。

后续界面观察被用户按 Esc 中止，未继续操控窗口。新原生入口的全程重启、新待办面板、管理员 UAC 实际显示及真实付费恢复均尚未验证。当前运行的旧实例需要正常关闭后重开，才能载入整轮最终源码。后续0.7.4构建与上传单列于发布记录；其他用户机器的安装版本仍需按其日志确认，不声称本机修复证明所有环境一致。
