# 墨流（InkFlow）0.3.1 发布说明

0.3.1 是面向公开分发的补丁版本，重点修复“新建小说 → 生成三个供比较”在部分推理模型上可能卡住的问题。

## 修复内容

- 开书构思统一使用短输出、关闭推理的专用调用。它只负责生成一个或三个可编辑方向，不再占用章节规划级别的推理预算。
- 如果模型连续两次未返回可解析的 JSON（例如推理 token 用尽而没有正文），新建窗口会显示基于用户偏好的本地保底方案。用户仍可编辑、采用或重新生成，不会被技术报错卡住。
- JSON 调用的第二次恢复尝试不再把 token 预算提高到原任务的两倍；DeepSeek 兼容接口会关闭推理，优先拿到完整 JSON。

## 在线更新

- Windows 安装包已配置为从 `littlewinter320/inkflow` 的公开 GitHub Release 检查更新。
- Release 必须同时保留安装包、`.blockmap` 和 `latest.yml`。详见 [更新发布指南](UPDATE_RELEASE_GUIDE.md)。
- 本版本不迁移小说数据库，不改变 Writer、Reviewer、Memory Keeper 三个正式角色，也不要求额外付费模型。

## 已知边界

- 保底方案是可编辑的临时起点，不会冒充模型成功输出，也不会自动写正文或正史。
- 仍未配置商业 Windows 代码签名证书，系统可能显示未知发布者提示。
- VS Code 扩展随 Release 提供 VSIX；上架官方 Marketplace 仍需单独的发布者账号。
