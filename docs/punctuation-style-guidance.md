# 墨流小说正文标点策略

这份规则用于 Writer 和 Reviewer 的小说正文，不套用于界面文字、规划文档或结构化数据。

## 依据

- 国家标准 [GB/T 15834—2011《标点符号用法》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=22EA6D162E4110E752259661E1A0D0A8) 规定：句号表示陈述语气的句末停顿，逗号表示句内一般性停顿，引号和括号用于标示具有特定性质的成分。标准判断停顿和语气，不按句子长短或固定数量分配标点。
- 人工文本抽样使用 Project Gutenberg 的公版中文作品：[鲁迅《呐喊》](https://www.gutenberg.org/ebooks/27166)、[鲁迅《彷徨》](https://www.gutenberg.org/ebooks/24042)、[刘鹗《老残游记》](https://www.gutenberg.org/ebooks/23850)。抽样只用于统计节奏，不复制作品表达。
- 自然写作检查遵循一个原则：标点是语义结果，不是制造“人味”的装饰。不能为了降低某个符号的数量，把它机械替换成另一种符号。

## 四类常用符号

### 句号

一个动作链、判断或感受真正收束时使用。句子长短不是判断条件。短句适合落重音、转折后的事实和人物当场反应，但连续把每个动作切成一句，会形成整齐的机器节拍。

### 逗号

用于同一口气中确有承接、转折或因果关系的分句。它不负责把多个动作、环境清单和解释无限串起来。需要换主语、换观察重点或让结果落地时，通常应收句或换段。

### 引号

用于人物实际说出的话、原样引用的字句和故事内可见文字。普通词语不靠引号制造强调。直接对白必须使用成对中文双引号，不能因为要求“少标点”而删掉；对白里的句末标点留在后引号内。叙述动作放在引号外，并保持人物说话与动作连续。

### 括号

小说旁白里尽量少用。补充解释若属于人物当下能感知的内容，应写进句子或动作。只有票据、标签、告示、档案原文等故事内物件确实带有括注时，才偶尔保留。

## 墨流的额外约束

- 按用户要求，小说正文禁用中文顿号“、”。并列内容要重写句法，或用“和”“跟”“与”连接。
- 不用分号、冒号、破折号、省略号或括号替代被删掉的逗号。
- Reviewer 只在出现明确顿号，或标点密度显著异常并伴随大量逗号串联句时阻止放行。普通的句长变化不按数字扣分。
- Writer 在交稿前检查三类模型化节奏：连续“观察—解释—总结”、每个动作单独成句、相邻段反复用同一人物开头或同一物件收尾。

## 本次正文样本观察

对《灰巷灯火》第 1 章与三份人工文本做了本地统计。第 1 章每百个有效字符约有 7.12 个逗号，位于人工样本约 5.82～7.26 的区间内；但句号约为每百字 5.02 个，明显高于人工样本约 2.50～2.86。问题因此不是简单的“逗号太多”，而是较多短句和解释性段落形成了均匀节拍。

修订方向应是合并真正连续的动作与感受，删除已经由细节表达过的解释，并减少重复锚定“煤气罐”“便签”“周德海”的段尾和段首。不能单纯把逗号改成句号，否则会进一步加重短句化。
