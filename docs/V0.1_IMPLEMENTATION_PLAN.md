# 墨流 v0.1 桌面版实施计划（历史基线）

> 这是早期实施基线，不代表当前 0.2 发布状态；当前说明见 `V0.2_RELEASE_NOTES.md`。

## 成功标准

1. 在 Windows 桌面生成可安装的 `InkFlow-Setup-0.1.0.exe`（历史目标）。
2. 安装后不依赖用户已有的 Python、Node 或命令行环境。
3. 桌面端可创建/打开项目、自然语言对话、编辑正文、运行三个 Agent 工作流、查看审查与回退。
4. 生成可安装的 VS Code `.vsix`，并能为当前工作区接入墨流 MCP。
5. 原有 CLI、MCP 与当时的测试保持兼容。
6. API Key 不进入源码、日志、Trace、小说文件或安装包。

## 实现顺序

1. 为 Python 引擎加入版本化 JSONL app-server 和桌面查询接口。
2. 补章节编辑、批注、搜索、统计和写作圣经的最小本地数据层。
3. 实现 Electron/React 桌面端三栏界面。
4. 实现 VS Code 项目树、选区操作和 MCP 注册/配置。
5. 生成 Python sidecar、NSIS 安装包和 VSIX。
6. 做定向测试、全量 pytest、前端构建、安装产物及干净环境启动核验。

## 数据变化

最终实现没有把桌面辅助数据塞进正史库。正史继续位于 `.inkflow/inkflow.db`；文档版本、批注、场景笔记与任务记录位于独立的 `.inkflow/studio.db`，由桌面端按需自动创建和增量补齐。用户可见的 `BOOK.md`、`PLAN.md`、`STATE.md`、`chapters/` 和 `reviews/` 继续兼容。
