2026-09-28：本次是正式 Writer 的默认表达引导更新，不是 DeepSeek 参数微调。没有启用此前未稳定胜出的学习画像，也没有修改用户原稿。

## 样稿观察

只读分析 `D:/小说/小说/章节/第一阶段/正文` 的13章，以及同目录作品的写作风格指南和注意事项。样稿有不同节奏：前几章短促分段较多，后几章更常把观察、判断、动作接在同一意脉中。结合用户当前“少断句、少格式化用词”的要求，默认取后期较连贯的表达习惯，不把整个样稿归成唯一句型。

- 第13章“我悄悄从山包另一侧滑下，绕开了那几条主干轨道，选择了一条看上去不怎么起眼的小支线。”连续动作共用视角，不必每个动作句号收尾。
- 第10章“（这传送体验，给个差评不过分吧？建议向秦家投诉，这也太不把人当人了。）”是处境中的内心插话，不是作者解释。可学习这种声音，不移植名字和剧情，也不要求每章都有吐槽。
- “不懂规矩就不来您这儿了”“这老狐狸，鼻子还挺灵的”依靠人物关系和口语表达态度，不必再补一套情绪标签或身体反应。
- 系统提示、网络用词属于原作题材；别的题材不自动加面板、热梗或第一人称。样稿错字、缺标点、数值矛盾不作为写法学习对象。

粗略排除标题和面板行后，第1—6章每组句末标点对应约15.7—19.6个计数字符，第10—13章约24.6—31.3个。此为启发式观察，受引号、面板识别和省略号影响，不是语言学句长、质量分或程序阈值。不能据此规定句长、标点占比、对白占比或动作比例。

当前明确的禁用顿号要求仍保留；样稿出现顿号不视为用户撤销要求。语法、必要停顿和成对对白引号照常保留，不以删除标点冒充自然表达。样稿附带的指南也是参考资料，不把其中固定情绪层数、每章热梗数量等偏好升级成所有作品硬规则。

## 实际运行范围

1. Writer正文、定点修订、选区修订、篇幅补足、篇幅压缩与独立场景草稿共享表达规则，防止后续补字又恢复机械短句。
2. 综合Editor、专项Reviewer和篇章复审理解同一声音；仅对可定位的问题提出修改，不能因长句、四字词或括号直接扣分。小说事实、人物知识、用户硬要求仍独立审核。
3. Coordinator理解“像我写的”“少断句”的原意并转交要求，不代写正文或替审核放行。
4. 删除多逗号句必须拆短的回归提示；密度只形成轻微观察项，不能单靠数量阻断。禁用顿号等明确要求未放松。
5. 使用原有模型调用，不增加Humanizer专用Agent、额外润色请求或自动改稿循环。Writer调用记录注明Humanizer-zh表达检查。

固定提示会增加少量输入，并让更新后的系统前缀首次改变；后续版本固定，未插入时间戳、随机样例或逐章统计。没有更改缓存编译和并发路径，不承诺缓存命中率提升或零成本。用户素材未上传远端，也未打包全文；代码内仅保留抽象文风说明。
